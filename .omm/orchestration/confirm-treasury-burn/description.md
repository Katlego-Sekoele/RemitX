`remitx_worker.tasks.confirm_treasury_burn(quote_id, tx_hash, error)`. On failure: all in-flight legs → `failed`, error logged, balances untouched. On success, in one commit: in-flight legs → `confirmed` with `confirmed_at`, hash stored on the token_burn leg as `xrpl_tx_hash`, then for every confirmed leg debit-side and credit-side account balances are updated. Zero matched rows = already settled, skip.
