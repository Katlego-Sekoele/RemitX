Fernet-encrypted signing material in environment variables: `PLATFORM_WALLET_SEED_ENCRYPTED` (+ `XRPL_ENCRYPTION_KEY`) for the XRPL treasury and `EVM_TREASURY_KEY_ENCRYPTED` (+ `EVM_ENCRYPTION_KEY`) for the EVM Treasury Wallet, generated by platform_wallet/scripts/. Synced to Render from GitHub environment secrets. Decrypted only inside the worker process.
