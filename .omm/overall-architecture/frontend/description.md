React Router v7 SPA (frontend/), built statically and served from a Render static site; `VITE_API_URL` points it at the API. Tailwind v4 configured in app/app.css, shadcn/ui (base-lyra over @base-ui/react) + Aceternity UI for effects, Phosphor icons, next-themes. Server state via TanStack Query over a Hey API client generated from frontend/openapi.json into app/client/ (gitignored). Auth by Clerk React. Routes are declared explicitly in app/routes.ts from two registries (app.routes.ts, admin.routes.ts) that also drive the sidebars.
