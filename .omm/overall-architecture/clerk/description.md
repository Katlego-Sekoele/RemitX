Hosted identity provider. The SPA uses Clerk React components for sign-in/sign-up/profile; the API verifies session JWTs in api/remitx_api/auth/clerk.py (`verify_request`, JWKS or `CLERK_JWT_KEY`) and lazily provisions a local `User` row on first sight (`UserRepository.ensure_provisioned`), fetching email/first name from Clerk only when inserting. Authorisation is RemitX's own RBAC, not Clerk's.
