Standalone one-off scripts (own pyproject) that create the platform's custodial wallets and print Fernet-encrypted secrets for `.env`: platform_wallet/scripts/create_xprl_platform_wallet.py (XRPL treasury seed → `PLATFORM_WALLET_SEED_ENCRYPTED` + `XRPL_ENCRYPTION_KEY`) and create_evm_platform_wallet.py (EVM Treasury key → `EVM_TREASURY_KEY_ENCRYPTED` + `EVM_ENCRYPTION_KEY`). Deliberately not imported by the app packages.
