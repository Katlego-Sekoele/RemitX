tools/loadtest — `make loadtest` (run.sh) builds a throwaway compose stack (docker-compose.yml, committed non-secret loadtest.env), seeds it once (prepare.py + seeder.Dockerfile), runs Locust (locustfile.py, tokens minted with `CLERK_JWT_KEY`) through stepped user loads per profile (profiles/*.json), optionally sweeping API/worker CPU/memory. fake_xrpl_worker.py replaces the XRPL burn with a delay calibrated from QA timings (qa_xrpl_timings.sql). loadtest_summary.py and to_canvas.py emit summary.json, performance-report.html and report.canvas.tsx per run under results/<timestamp>/.
