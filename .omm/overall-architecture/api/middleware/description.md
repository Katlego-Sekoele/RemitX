Request pipeline built in api/remitx_api/app.py and middleware.py. Outermost to innermost: CORSMiddleware (`CORS_ORIGINS`), `RequestIdMiddleware` (server-generated uuid, exposed as `X-Request-Id`, stored for audit correlation — inbound ids are never trusted), `MaxBodySizeMiddleware` (pure-ASGI cap = KYC document max + 2 MB, checks Content-Length then running total, returns 413 in the standard `{"detail"}` shape), then an http middleware that opens/closes a ContextVar-scoped DB session per request. A single `DomainError` exception handler maps domain refusals to HTTP.
