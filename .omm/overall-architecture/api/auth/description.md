api/remitx_api/auth/. clerk.py adapts a Starlette request to the Clerk SDK and returns `ClerkClaims` (nothing else knows Clerk exists). dependencies.py `get_current_user` is a sync dependency (runs in a threadpool so slow JWKS fetches stall only that request) that verifies the session and returns the provisioned local `User`. permissions.py resolves a user's effective permissions through user_roles → role_permissions and provides `RequirePermission(PermissionCode)`. Roles and permissions are seeded rows (models/orm/rbac_seed.py); toxic role combinations are rejected (toxic_combination).
