Authenticated customer endpoints, each router built with `create_customer_router`: me.py (profile/standing), kyc.py (onboarding application wizard), kyc_documents.py (raw-body upload, signed access URL, delete draft upload), beneficiaries.py, quotes.py (create/preview), remittances.py (confirm, list, detail/timeline), accounts.py (open fiat accounts, balances, history), dashboard.py, bank_accounts.py, withdrawals.py, integration_messages.py (throwaway end-to-end queue test).
