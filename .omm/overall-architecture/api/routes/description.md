Thin FastAPI `APIRouter` modules in api/remitx_api/routes/, registered in routes/__init__.py `register_routers`. Router factories in routes/routers.py enforce auth at mount time: `create_public_router` (health), `create_customer_router` (bearer + `get_current_user` + customer RLS binding) and `create_admin_router(permission)` (adds `RequirePermission` and admin RLS binding, mounted under /admin). Handlers carry no logic; their function names become generated client operation ids.
