Staff endpoints under /admin in routes/admin/, each router gated by a baseline `PermissionCode` with per-route escalation via `RequirePermission`: audit.py (audit log), roles.py and user_roles.py (RBAC grants), accounts.py (platform accounts), operations.py (overview metrics, stuck settlements list/retry), deposits.py (bank-statement CSV processing, approve unmatched deposits — `CASHIN_CONFIRM`), bank_accounts.py (verify/reject), withdrawals.py, kyc.py (review queue, decisions, risk overrides), kyc_documents.py (reviewer document access). Handlers never check roles or user flags themselves.
