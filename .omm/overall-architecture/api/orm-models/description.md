api/remitx_api/models/. orm/ holds SQLAlchemy entities (all inherit `Base`): users, roles/permissions/user_roles, accounts (types USER, REMITX_FIAT, REMITX_XRPL_WALLET, REMITX_REVENUE, EXTERNAL), transactions (types deposit, treasury_funding, remittance, fee, withdrawal, token_burn, beneficiary_payout; statuses pending/processing/confirmed/failed), quotes (ACTIVE/USED/EXPIRED), remittances, deposits, withdrawals, bank_accounts, beneficiaries, exchange_rates, audit_log, integration_messages, countries, and a large data-driven KYC catalogue (statuses, progression, tiers, risk ratings/signals, reason codes, onboarding steps/requirements, identity schemes) seeded by *_seed.py. kyc_lifecycle.py defines the KYC state machine. schemas/ holds Pydantic request/response models inheriting `Schema` with `UtcDateTime` timestamps.
