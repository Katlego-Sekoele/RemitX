FastAPI JSON REST API, package api/remitx_api/, built by the `create_app` factory in app.py and served by `python -m remitx_api` (dev) or `uvicorn asgi:app`. Strict layering: routes (HTTP only) → controllers (use-case orchestration) → services (domain rules) → repositories (SQLAlchemy) → ORM models. Also owns config, the Celery producer, OpenAPI conventions and Alembic migrations (api/alembic/). Deployed as a Render web service built from api/Dockerfile.
