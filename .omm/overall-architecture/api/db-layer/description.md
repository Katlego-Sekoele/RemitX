extensions.py builds the engine (Neon-pooler aware pool settings, SQLite FK pragma for tests) and the `db` Database facade with `open_session`/`close_session`. db/request_db_session.py keeps the session in a ContextVar so concurrent sync routes in anyio threads never share one. db/transaction.py `@db_transaction` commits once or rolls back a multi-step use case. db/rls.py stamps `current_user_id` and `is_admin_route` on the session and copies them onto each cursor as `SET LOCAL` so FORCE RLS policies filter rows; unbound sessions (worker, migrations, tests) see everything.
