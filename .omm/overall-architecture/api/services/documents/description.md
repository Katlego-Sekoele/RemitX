object_storage.py: `ObjectStorage` interface + `S3ObjectStorage` (boto3) for put/head/delete and presigned GETs that expire in minutes; swappable via `use_object_storage` in tests. upload_stream.py `read_upload` reads the raw request body (no multipart) and refuses on declared Content-Length or running total. file_signatures.py `sniff_content_type` identifies the file from leading bytes (and names SVG explicitly to refuse it as scriptable).
