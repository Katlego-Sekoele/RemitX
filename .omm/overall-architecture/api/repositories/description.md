SQLAlchemy data access in api/remitx_api/repositories/, built on the generic `Repository[T, ID]` (repository.py — `save`/`delete` commit). Domain-specific queries per aggregate: account, audit_log, bank_account, beneficiary, deposit, exchange_rate, integration_message, jurisdiction (country/identity scheme catalogue), kyc_application (incl. `get_standing` deriving a user's KYC standing and send-limit usage), kyc_document, kyc_onboarding (step/requirement catalogue), kyc_risk_rule, kyc_status_progression, overview (admin metrics), permission, quote (`mark_used` guarded flip), remittance, role, toxic_combination, transaction, user (`ensure_provisioned`, `lock`), user_role, withdrawal.
