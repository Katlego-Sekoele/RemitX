RemitX is a prototype cross-border remittance platform (UCT ECO5040W): customers deposit fiat (ZAR, USD, NAD, ZWL) into ledger accounts, get a frozen quote, and send to a registered beneficiary abroad. Settlement passes value through the UCTUSD stand-in token and is finalised asynchronously by a Celery worker once an on-chain burn confirms. The repo is a monorepo: a React Router SPA, a FastAPI JSON API, a Celery worker sharing the API package, a Solidity StokvelVault contract for the in-progress stokvel extension, Terraform for Render, and local-only QA tooling.
