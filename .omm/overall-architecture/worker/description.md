Celery worker package api/remitx_worker/ (same image family, api/Dockerfile.worker). Consumes tasks from Redis with `acks_late`, runs embedded beat (`-B`) for periodic reclaim, and owns the only code that decrypts treasury keys and touches a chain. In the cloud `python -m remitx_worker` runs a tiny /health HTTP server alongside Celery so it can live as a free Render web service that the API wakes on demand; locally compose runs `celery -A remitx_worker.celery_app worker -B`.
