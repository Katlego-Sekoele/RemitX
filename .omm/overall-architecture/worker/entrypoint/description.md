api/remitx_worker/__main__.py starts http.py's `serve_health` (ThreadingHTTPServer answering /health and / with `{"status":"ok"}` on $PORT) in a daemon thread, then `celery.worker_main(["worker","-B", "--concurrency=CELERY_CONCURRENCY"])`. Concurrency is explicit because free Render instances report host CPU count. A `worker_process_init` hook closes the inherited listening socket in forked children so an orphaned child cannot keep the port bound.
