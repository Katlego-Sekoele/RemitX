api/remitx_worker/evm_service.py. Loads the EVM Treasury Wallet by Fernet-decrypting `EVM_TREASURY_KEY_ENCRYPTED` with `EVM_ENCRYPTION_KEY`, read via `os.environ` (not `Config`) so the API's config cannot expose them. web3.py helpers with a minimal ERC-20 ABI (balanceOf, decimals, allowance, approve, transfer/burn) and `submit_transaction` using legacy gasPrice and the pending nonce. Not called by any task yet; foundation for the EVM burn (#278) and StokvelVault contribute/finalise (#273).
