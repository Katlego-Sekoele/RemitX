.github/workflows/deploy.yml, on push/PR to `main` and `stable` (and manual dispatch). `changes` resolves scope with path filters and maps branch → environment (`main`→qa, `stable`→prod); Terraform job applies shared then environment roots in HCP Terraform and syncs env vars; a migrate job runs `alembic upgrade head` against Neon from Actions; then API, worker and frontend are deployed via render-deploy.sh (Render auto-deploy is off). Serialised per branch by a concurrency group.
