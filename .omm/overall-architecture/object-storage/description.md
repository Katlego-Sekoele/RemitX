S3-compatible bucket for KYC document bytes: Neon Object Storage in the cloud, MinIO (with a `minio-setup` bucket job) locally. Accessed only through api/remitx_api/services/object_storage.py (`S3ObjectStorage`). The API writes objects after sniffing their leading bytes; browsers read them via presigned GET URLs that expire in minutes. Internal and signing endpoints are configured separately because compose hostnames differ from browser-visible ones.
