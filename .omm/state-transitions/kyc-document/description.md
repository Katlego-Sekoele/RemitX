`kyc_documents.status`: `pending` → `stored`. kyc_document_controller writes the `pending` row first (after ownership/limit, content-type allowlist + byte sniff, SHA-256 dedupe), puts the object in the bucket under that row's key, then marks it `stored`. A failure can only leave an unserved `pending` row, never an orphan object. Applicants may delete an upload only while the application is still editable; once submitted it is retained evidence (FICA §23). Every signed-URL read writes an audit entry.
