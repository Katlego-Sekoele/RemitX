One `deposits` row + one `transactions` (type deposit) row per bank-statement line. Matched at import (reference names an account in the line's currency) → transaction `confirmed`, `confirmed_by='system'`, audit `cashin.confirmed`. Unmatched → transaction `pending` with NULL destination account; staff later `approve_pending_deposit(deposit_id, account_reference)` confirms that same row via a guarded transition (two admins cannot both confirm). Re-uploaded lines are recognised by statement fingerprint and skipped as already reconciled.
