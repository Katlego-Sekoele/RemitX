Identity provider. Frontend: `@clerk/react-router` (SignIn/SignUp/UserProfile, `RedirectToSignIn`, session token). Backend: clerk-backend-api SDK in api/remitx_api/auth/clerk.py (`authenticate_request`; user email/name/image lookups). Config: `CLERK_SECRET_KEY`, `VITE_CLERK_PUBLISHABLE_KEY`, optional `CLERK_JWT_KEY` for networkless JWT verification (also used by the load test to mint tokens). The seeder creates Clerk users for QA personas.
