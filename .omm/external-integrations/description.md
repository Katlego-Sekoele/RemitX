Third-party services RemitX depends on at runtime and deploy time: Clerk for identity, ExchangeRate-API for FX, the XRPL Testnet (current burn) and XRPL EVM Testnet (UCTUSD + StokvelVault, migration target), Neon for Postgres and object storage, Render for hosting and Redis, HCP Terraform for infrastructure state, and a planned TrustMeBank mock bank. Every integration is wrapped in one module so the rest of the code never sees the vendor.
