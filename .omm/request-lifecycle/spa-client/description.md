The generated Hey API SDK (frontend/app/client) called through TanStack Query options (`api.<tag>.<op>()`). The Clerk session token is attached as a Bearer header; base URL from `VITE_API_URL`. lib/api.ts converts any non-2xx into `ApiError(message, status, body)`, flattening FastAPI's `{detail}` / validation arrays into one readable string. KYC uploads are sent as a raw body (`fetch(url, {body: file})`), not multipart.
